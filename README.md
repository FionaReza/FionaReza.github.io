# Fiona Reza — Oceanography Portfolio

A responsive academic portfolio for Fiona Reza, built with plain HTML, CSS, and JavaScript. The site uses separate static pages and can be hosted on GitHub Pages without a build step.

## Pages

- `index.html` — About Me (introduction and biography)
- `about.html` — Redirect to About Me
- `research.html` — My Research
- `project.html` — Projects I have worked on
- `publications.html` — My Publications
- `teaching.html` — Teaching Experience
- `cv.html` — CV
- `contact.html` — Contact

## Profile assets and details

The supplied curriculum vitae and laboratory portrait are included as `files/cv.pdf` and `images/profile.jpg`. The biography, education, research projects, publication status, conference posters, teaching record, field experience, skills, and awards on the site are based on the CV. Update your contact links and any dates or details when your CV changes. Edit `styles.css` to adjust the palette, typography, or layout.

## Publish with GitHub Pages

Push the repository to GitHub, then open **Settings → Pages**. Choose **Deploy from a branch**, select your publishing branch (usually `main`) and the `/ (root)` folder, then save. GitHub Pages will provide the site URL after deployment completes.
